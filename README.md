# IP Address Tracker

A responsive web application for searching IP addresses and domain names, displaying geolocation information, and
visualizing locations on an interactive map.

Built as a personal portfolio project based on
the [Frontend Mentor IP Address Tracker challenge](https://www.frontendmentor.io/challenges/ip-address-tracker-I8-0yYAH0).

## Tech Stack

- **React** — Component-based user interface
- **TypeScript** — Static typing
- **Vite** — Development server and production build
- **Vitest** — Test runner
- **React Testing Library** — Component testing
- **ESLint** — Code quality

**Planned:** Leaflet, React Context, geolocation API integration, and GitHub Actions.

## Project Status

🚧 **Work in progress**

The application foundation and testing environment are configured. Feature development is underway using Test-Driven
Development (TDD).

### Planned Features

- Search for IP addresses and domain names
- Display location, timezone, and ISP information
- Visualize geographic locations with Leaflet
- Responsive layout for desktop and mobile
- Loading, error, and input validation states
- Automated tests and CI checks

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/ip-address-tracker.git
cd ip-address-tracker
npm ci
```

### Development

```bash
npm run dev
```

### Testing

```bash
npm run test
```

Run all tests once:

```bash
npm run test:run
```

### Code Quality

```bash
npm run lint
npm run build
```

## Development Approach

This project follows an incremental development workflow focused on:

- Test-Driven Development (Red → Green → Refactor)
- Reusable and accessible React components
- Clear separation of responsibilities
- Type-safe code and maintainable architecture
- Feature branches and GitHub pull requests
- AI-assisted development with human review
